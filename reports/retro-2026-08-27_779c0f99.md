## 낭비 상위 2개 지점
1. **훅 오탐발 커밋 재시도** — 이미 Edit로 반영된 테스트 파일의 단순 `git add && git commit`이 3연속 거부. 근본 원인은 hook이 "파일 내용이 실제로 바뀌는지"가 아니라 "명령 문자열에 보호경로/테스트경로 등장 여부"로 넓게 매칭.
2. **PR 이후 CI 장애 규명(~12분+, 미해결)** — GitHub Actions 자체 `major_outage`를 훅 diff 비교→yaml 파싱→actionlint→rerun→GitHub 상태 페이지 조회로 단계적으로 좁혀 규명. 사용자 4연속 재질문이 이 구간에 집중 — 비동기 대기(ScheduleWakeup)가 "멈춘 것처럼" 보이는 UX 문제와 외부 장애가 겹쳐 체감 마찰 증폭.
