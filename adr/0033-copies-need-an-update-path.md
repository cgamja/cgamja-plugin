# ADR 0033 — 복사본에는 갱신 경로가 있어야 한다 (develop-update)

- 상태: 제안 (2026-09-01)
- 관련: adr/0023(버전 마커·드리프트 감지 — 이 ADR이 개정), adr/0014(선언이 사실의 원천), adr/0031(산문 규칙은 지켜지지 않는다), adr/0018(red-mark)

## 맥락

플러그인은 `~/.claude/skills/cgamja → cgamja-plugin` 심링크라 고치면 즉시 반영된다. **그런데 훅·rules·settings 는 대상 레포로 복사된다.** 복사본은 따라오지 않는다.

2026-09-01 실측:

| 레포 | 상태 |
|---|---|
| `~/app` (실사용) | 2026-08-22 훅으로 10일 — 오탐 4계열·우회 3종 미반영, `red-mark.sh` 파일 자체 없음 |
| `~/skill-test` | protect-bash 27줄 차이 |
| scratch 3개 | 훅 3개 구판 + red-mark 없음 |
| `smoke-vite` | **선언 자체가 없어 훅이 아무것도 보호하지 않는 상태** |

adr/0023 이 이걸 대비해 버전 마커와 드리프트 감지를 뒀는데 **한 번도 울린 적이 없었다.** 두 겹으로 깨져 있었다:

1. `# cgamja-hooks v<N>` 을 손으로 올려야 한다 — 0023 스스로 "수동 규율이다"라고 적어뒀고, 그날 세 번의 protect-bash 수정에서 아무도 안 올렸다. 마커는 `v3` 로 같은데 내용은 90줄 달랐다.
2. 템플릿 경로가 `$(dirname "$0")/../../…` 상대경로인데 그 뒤 `cd "$d"` 로 프로젝트 루트로 옮긴다 — **해석되지 않아 비교 자체가 통째로 건너뛰어졌다.** 1이 고쳐졌더라도 안 울렸다.

게다가 감지 범위가 `protect-bash.sh` 한 파일이었다. 같은 날 구판이던 `protect-files.sh`·`verify-on-stop.sh` 와 아예 없던 `red-mark.sh` 는 대상이 아니었다.

## 결정

**1. `develop-update` 스킬을 만든다.** `develop-setup` 이 "처음 한 번"이면 이것은 "그 뒤 계속"이다. 복사본 4축(훅 내용 · 훅 등록 · 선언 슬롯 · rules 구조)을 대조하고, 1~3 은 적용하고 4 는 보고한다.

**2. 드리프트는 정수 마커가 아니라 내용으로 판정한다.** `cmp` 로 템플릿과 사본을 비교하고, 템플릿의 훅 **전부**를 본다(없는 파일 포함). 버전 마커는 사람이 읽는 표식으로만 남긴다 — 판정 입력에서 뺀다.

**3. 선언이 없는 프로젝트는 update 대상이 아니다.** 훅은 선언에서 패턴을 읽으므로(adr/0014), 선언 없이 훅만 새로 깔면 "최신인데 아무것도 안 막는" 상태가 된다. `develop-setup` 으로 보내고 멈춘다.

**4. 갱신은 덮는 것과 보존하는 것을 구분한다.** 훅 스크립트는 그대로 덮고(프로젝트 고유값은 선언에서 읽으므로 손댈 이유가 없다), 선언은 **없는 키만 `null` 로** 추가하고, rules 내용과 프로젝트가 추가한 settings 항목은 건드리지 않는다.

## 왜 0023 을 고치는 것으로 끝내지 않나

0023 의 실패는 정밀도가 아니라 **종류**였다 — 사람이 지켜야 하는 규칙이었다(adr/0031). 감지를 고쳐도 "감지했으니 사람이 develop-setup 을 다시 돌린다"는 경로가 남는데, develop-setup 은 스택을 발견하고 도구를 고르는 무거운 절차라 훅 6개 복사를 위해 돌리기엔 과하다. 그래서 감지(0023 개정)와 **갱신 경로**(이 ADR)를 함께 둔다.

## 전제

- 훅 사본이 템플릿과 다르면 그건 갱신 누락이거나 누군가 사본을 고친 것이다. 후자라면 그 수정은 플러그인으로 올라가야 한다 — 프로젝트에 남기지 않는다.
- 최상위 선언 슬롯만 대조한다. 하위 키(`tests.layers`·`domains.allowed_edges`)는 프로젝트마다 정당하게 다르다.

## 재검토 조건

- `--apply` 가 프로젝트 고유 값을 덮은 사고 1회 → 적용을 제안 전용(diff 출력)으로 축소.
- 드리프트 경고가 떴는데 3세션 연속 방치 → develop-fe 진입 시 차단으로 승격(현재는 advisory).
- rules 구조 격차를 사람이 3회 연속 안 고침 → 템플릿 병합 자동화 재검토.
